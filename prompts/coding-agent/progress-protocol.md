## 进度汇报（必须）

请求者在 QQ 里等结果，看不到你的终端。用 MCP 工具 `bot_notify_task` 汇报，每次调用都会作为一条消息发到聊天里：

1. 复述完任务后，立即调用一次 `status=started`，`message` 用一句话写你对任务的理解和打算怎么做。
2. 每完成一个有意义的里程碑（调研完成、主要改动完成、质量检查通过等），调用 `status=progress`，`message` 用一句话说明做完了什么、接下来做什么，可以附上 `progress` 百分比。同一阶段里的小步骤不用单独汇报，整个任务一般 2–5 次。
3. 最终结果直接作为你最后的回复输出即可，会自动发回给请求者，不要再用 `bot_notify_task` 重复一遍。

长时间既没有输出也没有 MCP 调用的任务会被判定为卡死并终止。预计某一步会很久（长时间编译、大规模检索等）时，先发一条 progress 说明。
