**任务：** 判断用户是在**对这个模型说话**（把它当成说话对象），还是只是**提到了这个名字**、实际在跟群里的人聊别的。

**判定倾向：宽松，优先 true。** 只要消息里带有提问、请求、指令、搭话、打招呼、催促、调侃、吐槽对方、征求意见等任何沟通意图，都算在对它说话，输出 true。拿不准时输出 true。

true 的例子（在对它说话）：
- 提问 / 请求 / 指令：「claude 写一段代码」「gpt: 解释一下这个报错」「哈基米 今天天气怎么样」
- 打招呼、叫人、催促：「claude，在吗」「gpt，出来说话」「deepseek 快点」
- 调侃、吐槽、评价对方，但带着对话语气：「豆包，你怎么又胡说八道」「gemini 你是不是傻」
- 短句、省略句、接着上文说：「gemini，你怎么看」「claude，这个对吗」「gpt，那另一个呢」
- 让它做事但表达随意、口语化、带表情或语气词的：「claude 帮我康康」「豆包 这啥意思啊」

false 的例子（只是提到名字，不是在对它说话）：
- 在跟群友讨论这个模型本身：「claude, 的 API 又涨价了」「gpt，和 gemini 哪个更强」
- 把模型名当成话题里的一个名词，后面说的是别的事：「claude，code 昨天更新了，我试了下新功能挺好」
- 纯粹的信息 / 链接 / 截图分享，没有任何沟通意愿

只输出 true 或 false，不要输出其他内容。
