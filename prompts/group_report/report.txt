## 你的任务：生成昨日群聊每日汇报

仔细阅读上面的聊天记录，完成语义分析，把结果写成一个 JSON 对象。不要调用任何工具。统计数字由系统填进报告，你不用输出它们。

## 工作原则

- **点评有趣**：成员点评要幽默风趣但不冒犯人，像一个熟悉群友的老朋友在写周报
- **精选有料**：挑选最能代表昨日群聊风格的发言，评价要有见地
- **总评有洞察**：从聊天中提炼出有意义的观察，而不是泛泛而谈
- **语言生动**：避免公文式语言，用轻松活泼的风格，可以适当使用网络用语

## 点评风格参考

好的点评例子：
- "今日话痨担当，从早聊到晚不带歇气的，精力比手机电量还持久"
- "潜水一整天突然冒泡扔了个重磅观点，堪称深海鱼雷选手"
- "群里的百科全书，有问必答，知识储备像是把维基百科下载到了脑子里"

差的点评例子（避免）：
- "今天发言很多，很活跃"（太平淡）
- "表现不错，继续加油"（太官方）

## 精选发言评价参考

好的评价：
- "一句话道破了所有人想说但说不出来的感受，引发群内连锁共鸣，这就是名场面"
- "从技术角度给出了清晰的解释，救活了一个即将陷入争论漩涡的话题"

差的评价（避免）：
- "这条发言很好"（没有内容）
- "有深度"（需要具体说明什么深度）

### 1. 昨日热议话题（3-5 个）
- 提炼主要讨论话题，不要只写"闲聊"
- 每个话题用 1-2 句话概括讨论的核心观点和争议点
- 如果有明显的话题转折或冲突，着重提到

### 2. 活跃成员点评（3-6 位）
- 从上方成员发言统计中选最活跃和最有趣的成员
- 点评要**个性化**：根据这个人昨天实际说了什么来写，不要写通用的评价
- 可以给成员起有趣的"头衔"，如"昨日话痨""摸鱼冠军""深水炸弹"等
- 每人 1-2 句话，幽默但不冒犯
- userId 使用上方成员发言统计里的值

### 3. 精选发言（3-5 条）
- 挑选最有趣、最有代表性、最有深度、或引发最多讨论的发言
- content 截取原文最精华的部分（不超过 100 字）
- **详细评价**：为什么选这条？它为什么有趣/重要？引发了什么反应？（2-3 句话）
- 评价要具体、有观点，不要泛泛而谈

### 4. 群聊总评（3-5 句话）
- 总结昨天群聊的整体氛围和亮点
- 提到昨天最有意思的一个瞬间
- 可以用比喻或有趣的类比来形容昨天的群聊风格
- 如果消息量很少，可以调侃一下昨天大家都在忙什么

## 输出格式

只输出下面这个 JSON 对象，不要输出任何其他文字：

```json
{
  "topics": [
    {"title": "话题标题", "summary": "核心观点和讨论概括"}
  ],
  "memberHighlights": [
    {"userId": "12345", "comment": "个性化幽默点评"}
  ],
  "featuredMessages": [
    {"userId": "12345", "nickname": "群名片或昵称", "content": "原始发言精华部分", "comment": "详细评价"}
  ],
  "totalSummary": "昨天的群聊总评..."
}
```

- memberHighlights 和 featuredMessages 的 userId 就是聊天记录里 `昵称(userId)` 括号中的值
- featuredMessages.content 不超过 100 字
- 字符串里的双引号要转义，否则 JSON 无法解析
